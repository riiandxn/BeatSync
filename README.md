# BeatSync Cut v2.4 (Edits & CapCut Multi-Layer Timeline Edition)

Mobile-first beat-synced video editor combining **Instagram Edits** stacked multi-layer timeline and **CapCut** filmstrip editing workflow:
- **Real Video Filmstrip Thumbnails** inside every clip block + attached white **`+`** button at the end of the main video track.
- **Stacked Orange Filter / LUT Span Bars** (`Soft Light`, `Cinematic`, `Boost Warmth`, `Kodak Portra`, `CineStill 800T`, `Teal & Orange`) with independent in/out trim handles.
- **Stacked Purple Text & Auto-Caption Layer Bars** (`ADVERCASE`, `Edits Outline Serif`, `Bebas Neue`, plus custom `.ttf`/`.otf` uploads) with **direct touch-drag positioning on the preview canvas**.
- **CapCut Quick Rail & Lanes**: `Mute clip` toggle, `+ Add audio`, `+ Add text`, `Slip-Trim` with Ghost Filmstrip, `Duplikat` from 1 long video, `Split`, `Pinch-to-Zoom`, `Real-Time Beat Peak Detection`, `Extract Audio from Video`, `Live Voiceover + Auto-Ducking`, `Auto-Save Project History`, and `Native Android Export`.

## Cara Build APK Otomatis di GitHub
1. Extract seluruh isi ZIP ini lalu upload ke repository GitHub Anda (branch `main`).
2. Buka tab **Actions** pada repository GitHub.
3. Workflow **Build BeatSync Cut v2.4 APK** akan berjalan otomatis (~2-3 menit).
4. Setelah centang hijau, unduh **`BeatSync-Cut-v2.4-APK`** di bagian **Artifacts** paling bawah.
